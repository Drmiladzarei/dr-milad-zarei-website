# Dr Milad Zarei Website

Static website prepared for GitHub deployment and Supabase integration.

## GitHub Pages
1. Upload repository to GitHub.
2. Enable Pages from Settings > Pages.
3. Select main branch.

## Supabase
1. Create a Supabase project.
2. Copy `supabase/supabase-config.example.js` as `supabase-config.js`.
3. Put project URL and anon key.
4. Add Supabase CDN and `supabase/client.js` to pages where database/auth is needed.

Current website remains static and ready for backend connection.
